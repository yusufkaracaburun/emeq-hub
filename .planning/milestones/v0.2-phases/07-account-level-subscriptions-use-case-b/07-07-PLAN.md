Test-scope:
1. Setup: real Connection met `access_token` uit env-var `MOLLIE_CONNECT_TEST_ACCESS_TOKEN` (een persoonlijke Mollie Connect test-token van de developer)
2. Pre-flight: real Mollie call → `customers->create()` + `mandates->createForId()` (omdat een fresh customer geen valid mandate heeft; Phase 7 verwacht een bestaande `mandate_id` per D-19/D-20)

5. Cleanup: cancel de Mollie-subscription via Hub-DELETE (zelfde route) + assert state → Canceled
