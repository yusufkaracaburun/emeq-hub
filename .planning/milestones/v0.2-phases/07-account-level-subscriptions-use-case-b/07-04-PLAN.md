Routes (D-08):
- `POST /v1/account-subscriptions` → `AccountSubscriptionController@store` (ability `mollie:write,*`)
- `GET /v1/account-subscriptions?account_external_id=X` → `index` (ability `mollie:read,mollie:write,*`)
- `GET /v1/account-subscriptions/{id}` → `show` (ability `mollie:read,mollie:write,*`)
- `DELETE /v1/account-subscriptions/{id}` → `destroy` (ability `mollie:write,*`)
- `POST /v1/account-subscriptions/{id}/pause` → `PauseController` (ability `mollie:write,*`)
- `POST /v1/account-subscriptions/{id}/resume` → `ResumeController` (ability `mollie:write,*`)

Account-resolutie via body-veld `account_external_id` (D-11). Cross-Consumer-scope helper-pattern uit `ConnectionController::findOwnedConnection` (PATTERNS.md regels 457-466) gerefactored naar `findOwnedSubscription`.

Purpose: Plan 07-06 (feature-tests) test deze endpoints end-to-end. Plan 07-08 (acceptance) verifieert dat Scramble de routes oppikt op `/docs/api`.
