<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Filament admin → DB (PAT-issue) | Staff-User triggert `$consumer->createToken(...)` via Livewire-action; Sanctum's tokenize is server-side, plain-token wordt 1× geflashed in Notification (niet gepersisteerd) |
| Filament admin-form input → Consumer-model | `name`/`slug` validatie via `->required()`/`->unique()` server-side; geen mass-assignment risico door `#[Fillable]`-whitelist |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-05-01 | Information Disclosure | Plain-text PAT-token blijft in Filament-state na flash, of komt in browser-history | mitigate | `Notification::make()->persistent()` houdt notification zichtbaar maar wordt niet gepersisteerd in DB of Livewire-state; sluiten van panel ruimt token op. Documenteren in plan 09-11 ADR: super-admins moeten token meteen kopiëren. |
| T-09-05-02 | Spoofing | Een staff-User issued een PAT met `admin` (`*`) ability zonder super-admin-rol | accept | "Admin" preset is per ontwerp beschikbaar voor `staff` rol (CONTEXT.md D-03 — alle 5 presets in zelfde modal). PAT-issue is een audit-event; admin-allowlist + Phase 9-12 ADR moet noteren dat staff de "Admin"-preset bewust kan toekennen. Toekomstige tightening: super-admin-only voor `admin`-preset (backlog). |
| T-09-05-03 | CSRF | Livewire-action POST | accept | Filament v4 via Livewire forceert CSRF-token per request; geen handmatige config. |
| T-09-05-04 | Tampering | Mass-assignment via `Consumer::create($request->all())` | mitigate | Filament gebruikt `Form::getState()` met explicit form-schema (name + slug only); `#[Fillable]`-whitelist op Consumer-model blokkeert extra velden zoals `webhook_callback_secret`. |
| T-09-05-05 | Information Disclosure | `webhook_callback_secret` per ongeluk in Filament-form/table | mitigate | Form bevat ALLEEN `name` + `slug`. Tabel bevat ALLEEN `name`/`slug`/`accounts_count`/`connections_count`. webhook_callback_secret wordt nooit in form-schema gerefereerd. |
| T-09-05-06 | Tampering | Outdated PAT-preset bij nieuwe TokenAbilities-constant | mitigate | PatAbilityPresetsTest Test 1 (discovery-contract) faalt zodra een ability NIET in preset of PAT_CUSTOM_ONLY zit. CI fail → developer wordt geforceerd om PAT_PRESETS of PAT_CUSTOM_ONLY uit te breiden. |
| T-09-05-SC | Tampering | Geen package-install | accept | Plan 09-05 wijzigt alleen Resource-files + tests. Geen `composer require`. |
