<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| composer install → app | Twee nieuwe top-level packages (Filament + Spatie permission). Beide [LEGIT] per pre-install-gate. |
| `/admin/*` → browser | Filament's eigen middleware-stack (auth, CSRF) wordt gebruikt. CSRF protection is automatisch via Livewire (D-04 noten in CONTEXT). |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-02-SC | Tampering | composer installs van Filament + Spatie permission | mitigate | Pre-install blocking-human checkpoint (Task 0) — beide packages [LEGIT] op packagist met >M downloads + verified maintainers. Lockfile (`composer.lock`) committen voor reproducibility. |
| T-09-02-01 | Spoofing | Onbeschermde `/admin`-route na install (geen auth-config voor `web` guard met `users`-provider) | accept | Phase 3 heeft al `web`-guard + `users`-provider geconfigureerd voor toekomstig Filament gebruik (PROJECT-decision 03-02). `AdminPanelProvider->authGuard('web')` bindt hierop. Tests 1+3 bewijzen redirect-pad. |
| T-09-02-02 | Information Disclosure | Filament debug-info / asset-manifest in productie | accept | `APP_ENV=production` schakelt Filament's debug-features uit (default). Plan 09-11 (phase-close) verifieert deploy-config. |
| T-09-02-03 | Elevation of Privilege | Default Filament admin-panel zonder gate → iedere geauthenticeerd User kan in | mitigate | Geen User kan momenteel inloggen (`User`-model wordt pas plan 09-03 fillable + `canAccessPanel`). Smoke-test 3 bewijst dat unauthenticated geredirect wordt. Plan 09-03 sluit de gate via `canAccessPanel()`. |
| T-09-02-04 | CSRF | Filament-action POST/PATCH | accept | Filament v4 gebruikt Livewire onder de motorkap; Livewire forceert CSRF-token op elk Wire-request (`_token` in livewire/update-payload). Geen handmatige config nodig — Laravel-default `web`-middleware-stack dekt dit. Documenteer in plan 09-06 + 09-08 (Action-tasks). |
</threat_model>
