     de executor niet hoeft te zoeken. Bron: src/Exceptions/*.php gelezen tijdens planning. -->

ValidationException (400):
  public static function fromBody(string $body): self
  Properties: public readonly array $errorCodes, public readonly string $rawBody
  Behaviour: regex `\b([A-Z]{3}-\d{4})\b` over body, dedupe; message bevat "code(s) [...]" als matches, anders "HTTP 400. Body: ..."

AuthenticationException (401, 403):
  public static function tokenFetchFailed(int $status, string $body, string $credentialFingerprint): self
  Behaviour: message bevat "HTTP %d" en "fp:%s" (fingerprint truncated to 12 chars)

RateLimitException (429):
  public static function fromBody(string $body, ?int $retryAfterSeconds): self
  Properties: public readonly ?int $retryAfterSeconds
  Behaviour: message bevat "retry after Xs" als retryAfter != null

NotFoundException (404):
  public static function forUrl(string $url): self
  Behaviour: message format `'Snelstart API returned HTTP 404 for ' . $url`

ServerException (5xx):
  public static function fromResponse(int $status, string $body): self
  Behaviour: message format `'Snelstart API returned HTTP %d. Body: %s'`

SnelstartConnector::getRequestException(Response $response, ?Throwable $senderException): ?Throwable
  Match-branches: 400 → ValidationException, 401/403 → AuthenticationException, 404 → NotFoundException, 429 → RateLimitException, 5xx → ServerException, default → null

Saloon v3 Response constructie (voor mocks):
  Gebruik `Saloon\Http\Faking\MockResponse::make($body, $status, $headers)` als helper, dan `MockResponse->createPsrResponse()` om een echte Response te bouwen — OF mock direct met PHPUnit's createMock(Saloon\Http\Response::class) en stub status()/body()/header()/getPendingRequest()->getUrl().

  De master-plan-strategie zegt expliciet: vermijd de volledige MockClient-pipeline. Bouw dus de Response zelf (mock of stub-class) en roep `$connector->getRequestException($response, null)` aan.
