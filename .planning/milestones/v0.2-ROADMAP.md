# Milestone v0.2: Mollie + Connect + Subscriptions + Hub-skeleton

**Status:** ✅ SHIPPED 2026-05-17
**Phases:** 11 (Phase 2, 3, 4, 5a, 5b, 5c, 6, 7, 8, 9, 10)
**Total Plans:** 67

## Overview

v0.2 bouwt drie samenhangende lagen bovenop v0.1's gevalideerde Snelstart-pattern:

1. **`emeq/mollie-api` SDK** die `mollie/mollie-api-php` wrapt met multi-tenant credential-resolution + dual creds (API-key + OAuth).
2. **Hub-skeleton** met `consumers`/`accounts`/`connections`-tabellen, Sanctum-PAT-auth, Mollie Connect OAuth-broker, pass-through `/v1/mollie/*`- en `/v1/snelstart/{path}`-API, Snelstart webhook-ingress, Filament admin-paneel.
3. **Subscriptions** in twee use-cases: Cashier-Mollie voor Emeq→Consumers + eigen Account-level Connect-laag voor Accounts→eindgebruikers.

Sluit Hub-side af met Phase 8 (Naschool wiring via D-03 scope-fence): `SyncEnrollmentToSnelstartJob` + Mollie checkout-flow via Hub-Connect substrate landed; live E2E + Naschool-repo werk schuift naar v0.3.

**Wat v0.2 bewees:** twee fundamenteel verschillende providers (OData/clientkey + REST/OAuth2) productie-gevalideerd via één SDK-pattern, beide via dezelfde Hub geconsumeerd, multi-tenant + encrypted-at-rest + audit-logged + admin-managed.
