<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Filament-page | Authenticated Filament-staff crossen hier (Spatie permission gate) |
| Page-form-submit → ConsumerOnboarding-service | Pre-validated Filament form-data crosst hier |
| Cache-flash → list-consumers blade | Plain token/secret eenmalig in HTML; daarna Cache::pull deletes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-02-01 | Elevation of Privilege | OnboardConsumer-page-access | mitigate | `canAccess(): bool` enforces `auth()->user()?->can('manage-consumers')` per Phase-9 D-05 RBAC. Test: `actingAs($staffWithoutPerm)->get(OnboardConsumer::getUrl())` → 403 |
| T-08-02-02 | Information Disclosure | Plain PAT in Livewire wire:snapshot | mitigate | Submit-handler doet `Cache::put` + `redirect()` direct ná onboard — Wizard-state wordt NIET met plain-token bewaard. Cache-flash TTL 60s + Cache::pull (read+delete in één call). Test: `assertDontSee($plainToken)` op ListConsumers na 61s wait (of na Cache::pull simulatie via direct mocking) |
| T-08-02-03 | Information Disclosure | Plain webhook_callback_secret in wizard-state | mitigate | Zelfde Cache-flash pattern voor `pat-flash:webhook-secret:{livewireId}`. Test: `assertDontSee($plainSecret)` op zowel ListConsumers als EditConsumer |
| T-08-02-04 | Tampering | Onbekende provider-key in Stap 3 | mitigate | `Radio::make('provider')->options(...)` met `ProviderCredentialDescriptor::all()` als source — onmogelijk om unknown-key te submitten. Service-laag (PLAN 08-01) validateert ook (defense-in-depth) |
| T-08-02-05 | Information Disclosure | Validation errors lekken DB-state | mitigate | `slug niet uniek`-error: server-side `unique:consumers,slug`-rule + Filament-default inline-error met copy uit UI-SPEC regel 156 (`"Deze slug bestaat al — kies een andere."`) — geen DB-error-message leak |
| T-08-02-06 | Tampering | Auto-generated webhook_callback_secret entropy | mitigate | Indien Stap 1 secret leeg laat én user kiest "auto-generate" — gebruik `Str::random(48)` (zelfde entropy als Phase 4 `oauth_state`). Document choice in code-comment |
</threat_model>
