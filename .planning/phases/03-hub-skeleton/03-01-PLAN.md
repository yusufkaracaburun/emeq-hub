<objective>
Lever het multi-tenant data-model voor de Hub: drie tabellen (`consumers`, `accounts`, `connections`) met bijbehorende Eloquent-models + factories. De `Connection`-model krijgt encrypted casts en `#[Hidden]` op alle credential-velden zodat raw secrets nooit in `->toArray()`/JSON komen — dit is dé fundatie waarop Phase 4 (OAuth-broker) en Phase 5b (Snelstart-pass-through) credentials schrijven en lezen.

Purpose: HUB-01 vereist `consumers` + `accounts` + `connections` tabellen met provider-agnostische credential-opslag (OAuth-shape voor Mollie + key-based-shape voor Snelstart), encrypted-at-rest, met `consumer_id + external_id` als uniqueness-constraint zodat Phase 5b's pass-through-API per-Consumer Account-resolution doet.

Output: 3 migrations, 3 models, 3 factories. Geen routes, geen tests in dit plan (dat komt in 03-03 en 03-04). `php artisan migrate:fresh` slaagt; alle factories produceren valide rows.
</objective>

    ```php
    <?php

    namespace App\Models;

    use Database\Factories\ConnectionFactory;
    use Illuminate\Database\Eloquent\Attributes\Fillable;
    use Illuminate\Database\Eloquent\Attributes\Hidden;
    use Illuminate\Database\Eloquent\Factories\HasFactory;
    use Illuminate\Database\Eloquent\Model;
    use Illuminate\Database\Eloquent\Relations\BelongsTo;

    #[Fillable([
        'account_id',
        'provider',
        'status',
        'access_token',
        'refresh_token',
        'expires_at',
        'scopes',
        'client_key',
        'subscription_key',
        'subscription_id',
        'metadata',
        'revoked_at',
    ])]
    #[Hidden(['access_token', 'refresh_token', 'client_key', 'subscription_key'])]
    class Connection extends Model
    {
        /** @use HasFactory<ConnectionFactory> */
        use HasFactory;

        public function account(): BelongsTo
        {
            return $this->belongsTo(Account::class);
        }

        public function fingerprint(): ?string
        {
            $secret = match ($this->provider) {
                'snelstart' => $this->client_key,
                'mollie' => $this->access_token,
                default => null,
            };

            return $secret ? substr(hash('sha256', $secret), 0, 12) : null;
        }

        protected function casts(): array
        {
            return [
                'access_token' => 'encrypted',
                'refresh_token' => 'encrypted',
                'client_key' => 'encrypted',
                'subscription_key' => 'encrypted',
                'scopes' => 'array',
                'metadata' => 'array',
                'expires_at' => 'datetime',
                'revoked_at' => 'datetime',
            ];
        }
    }
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Application ↔ Database | Eloquent-models schrijven encrypted credentials naar Postgres; raw secrets mogen alleen via expliciete `$model->client_key`-access gedecrypteerd worden |
| Application ↔ logs/serializers | `->toArray()` / JSON-encoding mag nooit raw credentials lekken (route-responses, exception-renders, Telescope-payloads) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Information Disclosure | `App\Models\Connection` velden `access_token`/`refresh_token`/`client_key`/`subscription_key` | mitigate | `'encrypted'` cast op alle vier velden (`casts()`-methode) zorgt voor encryptie-at-rest via `APP_KEY`; verifieer met `assertNotSame($plainSecret, DB::table()->value())` in plan 03-04 |
