Cashier-Mollie's verwachte plan-shape (uit WebFetch op `config/cashier_plans.php`):
```php
[
    'naschool-license' => [
        'amount' => [
            'value' => '49.00',           // string, exact 2 decimals (Mollie-vereiste)
            'currency' => 'EUR',
        ],
        'interval' => '1 month',           // of '12 months' / '1 year'
        'description' => 'Naschool SaaS license — Emeq Hub access',
        // Optional advanced keys:
        //   'first_payment' => [...],     // overschrijft cashier.first_payment defaults
        //   'order_item_preprocessors' => [...],
    ],
]
```

Cashier's eigen `config/cashier_plans.php` heeft een `plans => []`-array op deze shape. Wij gebruiken DEZELFDE shape in `config/billing-plans.php` zodat PlanResolver::find() het resultaat verbatim aan Cashier kan doorgeven in plan 06-05.

Bestaande config-convention (uit `config/mollie.php`):
- `declare(strict_types=1);` op de top
- Geen array-keys met `default => ...`-pattern — direct array-return
- Comment-blokken inline om decisions te documenteren

Bestaande exception-conventie (uit `packages/snelstart-api`-laag uit Phase 5b en `packages/mollie-api`-laag uit Phase 2):
- `extends RuntimeException` (geen `Exception`-direct)
- Static `::factory()`-methods voor common error-shapes (bv. `MissingCredentialResolverException::notBound()`)
- `final class` waar mogelijk

Bestaande service-class-conventie (uit `app/Mollie/HubMollieCredentialResolver.php` + `app/Support/Mollie/MollieUpstreamErrorMapper.php`):
- Strict types op file-niveau
- Constructor-property-promotion waar Laravel-container-injection nuttig is
- `final` waar mogelijk
- PHPDoc op return-types met `array<string, mixed>`-style shapes

- Unit tests in `tests/Unit/Billing/` (nieuwe directory). Pure logic-tests zonder DB — PlanResolver leest alleen `config()`-helper, dus geen RefreshDatabase nodig.

    ```php
    <?php

    declare(strict_types=1);

    namespace App\Billing;

    use App\Billing\Exceptions\UnknownPlanException;

    /**
     * Config-driven plan-resolver voor Cashier-Mollie subscriptions.
     *
     * D-05: plans worden in config/billing-plans.php gedefinieerd (niet in
     *       Cashier's eigen vendor-config-tree).
     * D-06: simpele find()/all() public API zonder Eloquent Plan-model.
     *
     * Retourneert plan-arrays in Cashier-Mollie ^2.20's verwachte shape
     * zodat plan 06-05 ze 1:1 aan SubscriptionBuilder kan voeren.
     */
    final class PlanResolver
    {
        /**
         * @return array{amount: array{value: string, currency: string}, interval: string, description: string}
         *
         * @throws UnknownPlanException Wanneer de slug niet in config/billing-plans.php staat.
         */
        public function find(string $slug): array
        {
            /** @var array<string, mixed>|null $plan */
            $plan = config("billing-plans.{$slug}");

            if (! is_array($plan)) {
                throw UnknownPlanException::forSlug($slug);
            }

            /** @var array{amount: array{value: string, currency: string}, interval: string, description: string} $plan */
            return $plan;
        }

        /**
         * @return array<string, array{amount: array{value: string, currency: string}, interval: string, description: string}>
         */
        public function all(): array
        {
            /** @var array<string, array{amount: array{value: string, currency: string}, interval: string, description: string}> $plans */
            $plans = config('billing-plans', []);

            return $plans;
        }
    }
    ```
