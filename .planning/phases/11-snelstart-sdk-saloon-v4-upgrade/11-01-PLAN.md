| Boundary | Description |

| SDK → Saloon HTTP-laag | SDK vertrouwt Saloon's URL-resolution en authenticator-lifecycle. Saloon v3 had drie gedocumenteerde defecten in deze laag. |
| Developer-machine → SDK GitHub-repo | Push-rechten op `yusufkaracaburun/emeq-snelstart-api` geven controle over de versie die alle downstream Hubs (incl. productie) pakken. Mitigation: blocking-human-checkpoint op tag + push. |
