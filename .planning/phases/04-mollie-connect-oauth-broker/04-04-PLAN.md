Namespace `App\Http\Controllers\Api\V1\OAuth` (sub-namespace `OAuth/`). Extends `App\Http\Controllers\Controller`. Hub-tree → géén `declare(strict_types=1)`. Inhoud:

    ```php
    <?php

    namespace App\Http\Controllers\Api\V1\OAuth;

    use App\Http\Controllers\Controller;
    use App\Models\Connection;
    use App\Models\Consumer;
    use App\OAuth\OAuthFlowRegistry;
    use Illuminate\Http\Request;
    use Illuminate\Support\Str;

    class InitController extends Controller
    {
        public function __construct(private readonly OAuthFlowRegistry $registry) {}

        /**
         * @return array<string, string>
         */
        public function __invoke(Request $request): array
        {
            $validated = $request->validate([
                'account_external_id' => ['required', 'string'],
            ]);

            /** @var Consumer $consumer */
            $consumer = $request->user();

            $account = $consumer->accounts()
                ->where('external_id', $validated['account_external_id'])
                ->firstOrFail();

            $state = Str::random(48);

            $connection = Connection::create([
                'account_id' => $account->id,
                'provider' => 'mollie',
                'status' => 'pending',
                'oauth_state' => $state,
                'oauth_state_expires_at' => now()->addMinutes(30),
            ]);

            $scopes = config('services.mollie.connect.scopes');
            $redirectUrl = $this->registry->for('mollie')->getAuthorizationUrl($account, $scopes, $state);

            return [
                'connection_id' => (string) $connection->id,
                'redirect_url' => $redirectUrl,
            ];
        }
    }
    ```

    ```php
    <?php

    namespace App\Http\Controllers\Api\V1\OAuth;

    use App\Http\Controllers\Controller;
    use App\Models\Connection;
    use App\OAuth\OAuthFlowRegistry;
    use Illuminate\Http\JsonResponse;
    use Illuminate\Http\Request;

    class CallbackController extends Controller
    {
        public function __construct(private readonly OAuthFlowRegistry $registry) {}

        public function __invoke(Request $request): JsonResponse
        {
            $validated = $request->validate([
                'code' => ['required', 'string'],
                'state' => ['required', 'string'],
            ]);

            $connection = Connection::query()
                ->where('provider', 'mollie')
                ->where('status', 'pending')
                ->where('oauth_state', $validated['state'])
                ->where('oauth_state_expires_at', '>', now())
                ->first();

            if ($connection === null) {
                return response()->json(
                    ['error' => 'invalid_or_expired_state'],
                    400,
                );
            }

            $this->registry->for('mollie')->exchangeCode($connection, $validated['code']);

            return response()->json([
                'connection_id' => (string) $connection->id,
                'status' => 'active',
            ]);
        }
    }
    ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Consumer (Bearer-PAT) → POST /v1/oauth/mollie/init | Authenticated boundary; Sanctum + ability check |
| Untrusted browser → GET /v1/oauth/mollie/callback | Public route; state-parameter is auth (per D-07) |
| InitController → DB (pending Connection) | Write-boundary; state is veilig random (48 chars from Str::random) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-04-01 | Spoofing | CSRF on /callback (state-tampering) | mitigate | Tampered `state` → Connection-query vindt geen pending row → 400 met `invalid_or_expired_state`. Test 2 in CallbackTest bewijst dit. Voldoet aan ROADMAP SC-5. |
| T-04-04-02 | Tampering | Replay attack on /init | mitigate | Een replay van `POST /init` maakt een NIEUWE pending Connection met NIEUWE state — geen state-reuse mogelijk. State-TTL 30min (D-02) limiteert lifetime van orphan rows; Plan 04-05 prune-command ruimt deze op. |
| T-04-04-03 | Tampering | Authorization-code interception (RFC 6749 §10.5) | mitigate | HTTPS-only redirect_uri (env-config). Pure infrastructure-niveau; geen code-mitigation in Phase 4. |
| T-04-04-04 | Repudiation | Idempotency-replay van /callback | mitigate | 2e callback met dezelfde state vindt geen `status=pending` rij meer → 400. Test 4 (`test_second_callback_with_same_state_returns_400`) dekt dit pad expliciet. D-03 invariant. |
| T-04-04-05 | Information Disclosure | Cross-Consumer Account-enumeration via /init | mitigate | `$consumer->accounts()->where('external_id', $id)->firstOrFail()` returnt 404 voor cross-Consumer (geen 403 die het bestaan zou onthullen). Test 3 in InitTest. |
| T-04-04-06 | Elevation of Privilege | Bypass ability-check | mitigate | Sanctum's `ability:mollie:write` middleware op route-laag; Test 2 in InitTest bewijst rejection van MOLLIE_READ-token met 403. |
| T-04-04-07 | Information Disclosure | Open-redirect via callback | accept | `/callback` returnt JSON, géén HTTP-redirect naar Consumer-supplied URL (D-08). Out-of-scope tot Consumer-supplied redirect ooit toegevoegd wordt. |
</threat_model>
