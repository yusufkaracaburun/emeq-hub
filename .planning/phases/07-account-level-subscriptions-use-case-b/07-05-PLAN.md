## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mollie → Hub | `POST /webhooks/mollie/{connection_id}` is publieke ingress (geen Sanctum). Signature-verify + connection-lookup zijn de auth-laag. Refactor mag deze auth-laag NIET zwakken. |
| Webhook-payload → Hub-state | Payload-id wordt nu naar Hub-state-machine gerouteerd (D-15). Een spoofed of replay payload kan financial-state corrumperen als anti-spoof faalt. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-07-05-01 | Spoofing | Spoofed `tr_*`-payload → PaymentWebhookHandler doet Mollie GET; bij success geen Hub-state-mutatie | mitigate | `PaymentWebhookHandler::handle` doet `Mollie::client()->payments->get($id)` als anti-spoofing (Mollie 404 = spoof). Result.antiSpoofFailed() → controller 400 + geen fan-out (D-18 stap 6 guard). |
| T-07-05-02 | Spoofing | Spoofed `sub_*`-payload → SubscriptionWebhookHandler matched op `connection_id + mollie_subscription_id` | mitigate | Handler filtert op `connection_id` van de URL-segment (vooraf via signature-verified Connection-lookup); spoofed `sub_*` met andere connection_id → `skip('unknown_subscription')` + geen state-mutatie. Real `sub_*` triggert `syncFromMollie` die zelf een Mollie GET doet (anti-spoof). |
| T-07-05-03 | Tampering | Replay-attack — zelfde webhook-payload 2x → 2 state-flips | mitigate | `AccountSubscriptionManager::recordPaymentEvent` is idempotent voor paid-status (zelfde last_payment_status). Voor mandate_invalid: tweede call doet `Active → Paused`, maar `Paused → Paused` is self-transition (no-op per plan 07-02). |
| T-07-05-04 | Repudiation | Webhook-state-update zonder spoor | mitigate | `AccountSubscriptionManager::transitionTo` logt elke flip met `account_subscription.transition` (plan 07-03). Spatie `webhook_calls`-audit-rij blijft schrijven (D-18 stap 6) zolang `result.shouldAudit()`. |
| T-07-05-05 | Denial of Service | Onbekende `mdt_*`-payload → handler doet niets, Mollie krijgt 202 | accept | D-15 §"mdt_": geen state-mutatie, geen fan-out, audit-rij voor diagnose. Mollie verzendt vandaag geen mandate-events; placeholder voor v0.3+. |
| T-07-05-06 | Tampering | Refactor breekt D-31 invariant (Phase-5a tests stuk) | mitigate | Tasks 2 + 3 vereisen `MollieWebhookIngressTest` + `MollieWebhookAntiSpoofingTest` groen. Result.shouldFanOut() blokkeert specifiek anti-spoof-pad (matched bestaand testgedrag). |
